# 학급관리 앱 + 처리 예정 위젯 (안드로이드)

휴대폰에서 학급관리 앱을 브라우저 없이 **앱으로** 열고, 오늘 화면의 «처리 예정»(출결 서류 · 일정 · 제출물 · 할 일 · 필사)을 홈 화면 위젯으로 보여줍니다.

- 앱 아이콘(초록색 '출결')을 누르면 출결 앱이 앱 화면으로 열립니다. 아이콘을 길게 누르면 **위젯 설정**.
- 출결 앱 화면의 데이터는 이 앱 안에 따로 저장됩니다. 처음 한 번 출결 앱 안에서 **설정 → 휴대폰 ↔ PC 동기화**를 연결하면 기록이 받아집니다 (읽기·쓰기 토큰).
- 백업·나이스 파일 저장은 저장 위치를 고르는 창이, 나이스 파일 보내기는 공유 창(구글 드라이브 등)이 뜹니다.

```
처리 예정 4                        9:40 확인  ⟳
──────────────────────────────────────────
출결 서류 2
D+1  7. 이바다   체험학습 신청서
     11/2(월) 체험학습                   ← 기한 지나면 빨갛게, 묶음 맨 위로
     3. 김하늘   결석계
     10/20(화) 질병결석
일정 1
D-0  김하늘   학부모 상담                  ← 남은 날. 지난 일정은 감춘다
     10/30(금) 15:00
제출물 1
D-3  현장학습 동의서   3명 안 냄
필사 1
     1. 김하늘   3장 남음
     10/20(화) 휴대폰 사용
```

- 예전 학급관리 앱이 올린 요약(받을 서류만)도 그대로 읽어 «출결 서류» 묶음 하나로 보입니다.

- 목록이나 제목을 누르면 출결 앱이 열립니다. 서류를 '받음'으로 바꾸고 앱을 나오면 20초쯤 뒤 위젯도 새로 받습니다.
- 1시간마다 새로 받고, ⟳ 를 누르면 바로 받습니다. 출결 앱에서 '받음'을 누른 뒤 위젯에 반영되기까지 최대 1시간 걸릴 수 있습니다.
- 출결 앱의 **휴대폰 ↔ PC 동기화**를 켜 둔 경우에만 동작합니다. 앱이 동기화할 때 처리 예정 요약을
  같은 잠금 비밀번호로 잠가 동기화 저장소의 `sync/pending.json` 에 함께 올리고, 위젯은 그것을 받아 풉니다.

## 설치

1. 휴대폰에서 이 저장소의 **Releases → 받을 서류 위젯** (이름은 예전 그대로일 수 있음) 에서 `attendance-widget.apk` 를 받아 설치합니다.
   처음이면 '출처를 알 수 없는 앱' 설치를 브라우저에 허용해야 하고, Play 프로텍트 경고가 나올 수 있습니다(플레이 스토어 앱이 아니라서).
2. 초록색 **'출결'** 앱을 열고 **설정 → 휴대폰 ↔ PC 동기화** 에 저장소·토큰(Contents 읽기·쓰기)·잠금 비밀번호를 넣습니다.
   기록이 받아지고, 위젯도 이 설정을 그대로 씁니다 (위젯용 토큰을 따로 만들 필요 없음).
3. 홈 화면을 길게 눌러 위젯 → **처리 예정** 을 끌어다 놓습니다.

위젯 상태는 '출결' 아이콘을 **길게 눌러 → 위젯 설정** 에서 봅니다.

## 새 버전으로 바꿀 때

저장소 Secrets 에 서명 키(`WIDGET_KEYSTORE_B64`, `WIDGET_KEYSTORE_PASSWORD`)가 있으면 늘 같은 키로 서명되어
새 APK 를 그냥 덮어 설치하면 됩니다 (데이터·설정 그대로). Actions 의 '어떤 키로 서명했나' 단계에 어느 키였는지 나옵니다.

Secrets 가 없으면 빌드할 때마다 키가 달라 **덮어 설치가 안 되고**, 지우고 새로 깔아 동기화를 다시 연결해야 합니다.
키를 새로 만들려면:

```bash
keytool -genkeypair -keystore release.keystore -storetype PKCS12 -alias widget -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 release.keystore   # 이 출력이 WIDGET_KEYSTORE_B64, 키 비밀번호가 WIDGET_KEYSTORE_PASSWORD
```

키 파일은 잃어버리지 않게 따로 보관합니다.

## 보안

- 위젯 앱은 토큰·잠금 비밀번호와 풀어 둔 처리 예정 목록을 이 앱 안 저장 공간에만 둡니다(다른 앱은 못 읽음).
  다만 휴대폰 잠금이 풀린 상태라면 홈 화면에 학생 이름과 서류가 보이니, 휴대폰 화면 잠금은 꼭 걸어 두세요.
- 동기화 저장소에 올라가는 요약도 출결 데이터와 같은 방식으로 잠가서 올라갑니다.

## 개발

Android Studio 로 이 폴더(`android-widget/`)를 엽니다. `./gradlew testDebugUnitTest assembleRelease`.
`app/src/test/resources/pending-fixture.json` 은 출결 앱의 `encrypt()` 로 '시험용 비밀번호' 를 써서 잠근 것으로,
출결 앱과 위젯의 잠금 방식이 맞는지 확인합니다.
