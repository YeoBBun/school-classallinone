# 학급관리 앱 + 처리 예정 위젯 (안드로이드)

휴대폰에서 학급관리를 브라우저 없이 **앱으로** 열고, 오늘 화면의 «처리 예정»(출결 서류 · 일정 · 제출물 · 미처리 · 필사 · 기타)을 홈 화면 위젯으로 보여줍니다.

```
처리 예정 4                        9:40 확인  ⟳
──────────────────────────────────────────
출결 서류 1
D+1  7. 이바다   체험학습 신청서          ← 기한 지나면 빨갛게, 묶음 맨 위로
     11/2(월) 체험학습
일정 1
D-0  김하늘   학부모 상담                  ← 남은 날. 지난 일정은 감춘다
     10/30(금) 15:00
기타 2
D-3  학급 문고 정리
     교무회의 자료
```

- 앱 아이콘(파란색 '학급관리')을 누르면 학급관리가 앱 화면으로 열립니다. 아이콘을 길게 누르면 **위젯 설정**.
- 앱 안에서는 **휴대폰의 구글 로그인**을 씁니다 (구글이 앱 안 웹 화면 로그인을 막아서). 한 번 로그인하면 웹처럼 한 시간마다 다시 로그인하지 않아도 됩니다.
- 위젯은 같은 구글 계정으로 드라이브 '학급관리' 폴더의 `class-pending.json`(학급관리가 맞출 때마다 잠금 비밀번호로 잠가 올리는 요약)을 받아 풉니다.
- 1시간마다 새로 받고, ⟳ 를 누르면 바로 받습니다. 앱에서 고치고 나오면 20초쯤 뒤 위젯도 새로 받습니다.
- 학급관리 기록은 이 앱 안에 따로 저장됩니다 (휴대폰 크롬과 별개). 구글로 맞추면 PC·크롬과 같은 기록이 됩니다.

## 설치

1. 휴대폰에서 이 저장소의 **Releases → 학급관리 앱 (안드로이드)** 에서 `class-app.apk` 를 받아 설치합니다.
   처음이면 '출처를 알 수 없는 앱' 설치를 브라우저에 허용해야 하고, Play 프로텍트 경고가 나올 수 있습니다(플레이 스토어 앱이 아니라서).
2. **학급관리** 앱을 열고 머리글의 **[구글 로그인]** → 계정을 고르고 드라이브·캘린더를 허락 → 잠금 비밀번호(PC에서 정한 것)를 넣습니다.
3. 홈 화면을 길게 눌러 위젯 → **처리 예정** 을 끌어다 놓습니다.

위젯 상태는 '학급관리' 아이콘을 **길게 눌러 → 위젯 설정** 에서 봅니다.

## 처음 한 번: 구글 클라우드 콘솔 (앱 만드는 사람)

학급관리 웹과 **같은 프로젝트**에 안드로이드 클라이언트를 하나 더 만든다 (같은 프로젝트라야 웹이 드라이브에 만든 파일을 앱이 읽는다).

- Google 인증 플랫폼 → 클라이언트 → 클라이언트 만들기 → 유형 **Android**
- 패키지 이름: `io.github.yeobbun.classapp`
- SHA-1 인증서 디지털 지문: 서명 키의 SHA-1 (Actions 의 'Android app' 실행 기록 '어떤 키로 서명했나' 에 찍힌다)

## 새 버전으로 바꿀 때

저장소 Secrets 에 서명 키(`WIDGET_KEYSTORE_B64`, `WIDGET_KEYSTORE_PASSWORD`)가 있으면 늘 같은 키로 서명되어
Releases 에서 새 APK 를 받아 덮어 설치하면 됩니다. 키가 바뀌면 구글 로그인도 안 되니(SHA-1 이 달라짐) 키 파일은 잘 보관합니다.

## 개발

Android Studio 로 이 폴더(`android-widget/`)를 엽니다. `./gradlew testDebugUnitTest assembleRelease`.

- 위젯 앱은 잠금 비밀번호와 풀어 둔 처리 예정 목록을 이 앱 안 저장 공간에만 둡니다(다른 앱은 못 읽음).
